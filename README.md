# 掷柶游戏 · 微信小游戏 (Yut Nori / 윷놀이)

一款基于微信小游戏原生框架实现的传统掷柶（Yut Nori）棋盘游戏。纯 Canvas 2D 渲染，无第三方框架依赖，支持双人同屏、人机对战和 WebSocket 在线对战。

> 状态：个人练手项目，核心玩法已可玩，仍在持续打磨中。

## ✨ 功能特性

- **三种对战模式**：双人同屏（PVP） / 人机对战（AI） / 在线对战（WebSocket）
- **完整掷柶规则**：
  - 🟢 绿色面数量决定步数：`도`(1步) `개`(2步) `걸`(3步) `윷`(4步) `모`(5步)
  - `윷`/`모` 掷出后可**再掷一次**
  - `백도`(백도, -1步) 让棋子退回起点
  - 吃光对方棋子可获得**额外回合**
- **棋盘系统**：外圈主路 + 两条对角捷径（diag1/diag2）+ 太极中心点
- **视听效果**：胜利烟花粒子特效 + WebAudio 程序化音效（无外部音频文件）
- **屏幕自适应**：横屏，按设备尺寸自动缩放

## 🛠 技术栈

- 微信小游戏原生（无第三方框架）
- Canvas 2D 渲染 + `requestAnimationFrame` 游戏循环
- WebSocket 联机（需自备服务端）

## 🚀 运行方式

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「小游戏」→ 导入项目，目录选择本仓库根目录
3. AppID 可用测试号，或替换为自己的（项目内当前为 `wx4ab95d698252dbea`）
4. 编译运行（已配置横屏 `landscape`）

## 🌐 在线模式说明

`game.js` 顶部 `NetworkConfig.WS_URL` 默认指向局域网地址 `ws://192.168.1.5:3000`，**需要你自行部署一个 WebSocket 服务端**（负责房间匹配、转发游戏动作）。上线时改为 `wss://你的域名/ws` 即可。

## 📁 目录结构

| 文件 | 说明 |
| --- | --- |
| `game.js` | 游戏主逻辑：渲染、规则判定、AI、联机、特效 |
| `game.json` | 小游戏全局配置（横屏、超时、权限等） |
| `project.config.json` | 微信开发者工具项目配置（含 AppID） |
